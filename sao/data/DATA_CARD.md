# Data Card

## Training Archive

`critic_ep3_qwen_mixed_r1_r3_training_data_v1.tar.gz` contains the complete
processed mixed dataset used for the recorded run:

- 989 source trajectories;
- 988 retained trajectories: 200 Function and 788 SWE-smith;
- 888 training trajectories: 180 Function and 708 SWE-smith;
- 100 mixed-dataset validation trajectories;
- 604 failures and 384 successes across retained rows;
- 22,894,483 total context tokens;
- 3,652,290 supervised assistant action tokens;
- one 69,991-token failure quarantined without truncation.

Files inside the archive:

- `input_ids.npy`: concatenated token IDs (`int32`);
- `action_mask.npy`: concatenated assistant-action mask;
- `samples.jsonl`: offsets, lengths, split, family, reward, and provenance hashes;
- `dataset_manifest.json`: source and split statistics;
- `audit.json`: integrity checks;
- `excluded_overlength.jsonl`: quarantined records.

The expanded JSON/JSONL metadata is also available under `metadata/training/`.

## Fixed Holdout Archive

`critic_ep3_fixed_holdout40_v1.tar.gz` contains the earlier 398-row processed
dataset whose `split=validation` rows form the formal 40-trajectory holdout.
The full token arrays are retained because validation row offsets refer into
those arrays. The trainer filters to 20 Function and 20 SWE-smith validation
rows at evaluation time.

Expanded metadata is available under `metadata/holdout40/`.

## Target and Mask

The target is the terminal verifier result:

- positive: `benchmark_resolved=true`;
- negative: `benchmark_resolved=false`;
- gamma: `1.0`;
- no intermediate reward is present.

Only assistant action and assistant end-of-turn tokens receive loss mask `1`.
System, user, tool observation, and assistant header tokens remain visible
context but receive mask `0`.

## Leakage Controls

Function trajectories are split by task ID. SWE-smith trajectories are split
by repository, with at least four validation repositories. The audit reports
no train/validation group overlap, unique trajectory hashes, aligned token and
mask lengths, and exact whole-conversation versus message-wise tokenization.

## Provenance and Limitations

The data was generated by the Epoch3 Qwen Actor and terminal benchmark
verifiers. The archives contain tokenized trajectories rather than raw message
text, but token IDs can be decoded with the matching tokenizer and should not
be treated as anonymized data.

This directory does not grant new rights over Qwen model artifacts, benchmark
tasks, repositories, or other upstream material. Review all applicable
upstream licenses before public redistribution or commercial use. Model and
optimizer weights are intentionally not included.
